# 纏繞畫生成器 · Zentangle

用點矩陣定義區域，再填入各種纏繞圖元，自由組合出禪繞畫，匯出 PNG 或 SVG。

**線上使用**：https://kftseng2oo1.github.io/zenfig/

## 主要功能
- **區域**：新增多個區域，各自命名、設定顏色
- **點矩陣**：用畫筆、矩形或塗區域的方式圈出圖元範圍；可清除或填滿空格
- **圖元庫**：花瓣、螺旋、葉片、鱗片、同心圓、鵝卵石等基本紋樣；凱爾特結、曼陀羅、佩斯利等圖騰；泰雅、排灣、阿美、賽夏、鄒、魯凱等原住民紋樣；拼布方塊
- **疊加／減去**：多層圖元組合，保留操作紀錄可重繪
- 參數：填充、擾動、壓力線寬、隨機大小、隨機旋轉；也有隨機示範
- ⬇ 下載 PNG、SVG

## 技術與依賴
- 單檔 HTML PWA（`index.html` 內含全部 HTML/CSS/JS），`manifest.json` + `sw.js` 提供安裝到主畫面與離線快取。
- Canvas 繪製，SVG 匯出，純前端
